First release of **DeckCraft AR** — an Arabic interface, Arabic presentations and kashida levels built into [DeckCraft](https://github.com/storytold/deckcraft) 0.7.0.

## Downloads
- **`DeckCraft-AR-0.7.0-windows-x64.msi`** — Windows installer (64-bit). Self-contained: no internet, no Visual C++ redistributable. Installs beside DeckCraft, not over it.
- **`DeckCraft-AR-0.7.0-windows-x64-portable.zip`** — the same program without an installer: unzip and run `deckcraft.exe`.

The build is not code-signed; SmartScreen warns once on first run.

## What's in ar.1
- **Arabic interface** (*File › Preferences › DeckCraft AR*, or follows the system): 1,000+ strings translated, the whole interface right-to-left — tabs, ribbon groups, buttons, the slide list, the status bar — with Noto Sans Arabic embedded.
- **Arabic presentations by default**: a new presentation starts right-to-left with an Arabic-capable theme font (switch it off in Preferences).
- **Kashida levels** — *Home › Paragraph › Kashida* Low / Medium / High share a justified line's slack between the letter joints and the spaces; saved to PowerPoint as `justLow`, kept exactly in `.deckcraft` files.
- **Visual help on every button and every menu item** (250+ entries): a drawn thumbnail that plays as a little film, a plain-words explanation ending in an example, in English and Arabic ("Explain buttons in Arabic too" in Preferences); menu items show their picture beside their name.
- **Built-in developer systems** under *View › DeckCraft AR*: UI Kit gallery, icon sheet, a self-test that runs every command on a scratch presentation, a checklist.
